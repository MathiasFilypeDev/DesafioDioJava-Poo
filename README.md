# 👋 Bem-vindo ao Repositório do Desafio POO - DIO 📚💻⚙️


## ✨ Sobre o Projeto
Este repositório contém a minha solução e evolução para o **Desafio de Programação Orientada a Objetos (POO)** da **DIO** (Digital Innovation One). 
Aqui aplico conceitos fundamentais de POO (como Herança, Polimorfismo, Encapsulamento e Abstração) utilizando **Java**.

🎯 **Missão:** Desenvolver código limpo, estruturado e aplicando as melhores práticas de POO.  
📌 **Objetivo:** Consolidar a lógica de programação orientada a objetos e documentar a arquitetura através de diagramas e versionamento profissional.
